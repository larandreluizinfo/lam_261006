# AGENTS.md

Diretrizes para agentes de codificação neste repositório.

## Git

- **Toda alteração deve ser commitada e enviada (`push`).**
- Nunca deixe mudanças pendentes no working tree ao concluir uma tarefa.
- Antes de commitar: rode o lint e o typecheck disponíveis no projeto.
- Escreva mensagens de commit curtas e no estilo do repositório (ex.: `Add X`, `Fix Y`).
- Nunca commite segredos, chaves ou credenciais.
